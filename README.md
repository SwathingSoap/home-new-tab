# Дом — новая вкладка для Firefox

Новая вкладка в духе Tabliss, но с тем, что нужно мне. Логика данных перенесена из ТВ-лаунчера
(`../tv-launcher`).

- часы по центру, дата, флаг страны выхода в интернет (видно, включён ли VPN) и пинг;
- закладки из папки «Новая вкладка» (любое место в дереве закладок), иначе с панели закладок;
- курсы USD/EUR/KZT ЦБ РФ с графиком за 30 дней (зелёный — рост за период, красный — падение;
  тенге — за 100);
- погода Open-Meteo + 3 дня, восход и закат; при наведении — прогноз на 12 часов,
  «☔ дождь через N ч»; «🧲 магнитная буря», если прогноз NOAA на сутки даёт Kp ≥ 5;
- DTF: популярное «Игры» ⇄ «Фильмы и сериалы», смена каждые 30 с (при наведении — пауза),
  если задержать курсор на новости, раскрывается первый абзац; список прокручивается колесом;
- Steam: скидки из вишлиста (NEW — скидка младше 2 дней, 🔥 мин. — исторический минимум по CheapShark,
  % отзывов), «Бесплатно» — раздачи игр в Steam (GamerPower) с датой окончания,
  «Новинки Steam», «Скоро выйдет» из вишлиста; разделы сменяются каждые 30 с, списки прокручиваются;
- «Онлайн»: топ-15 игр Steam по онлайну (место, ▲▼ к прошлой неделе, пик за сутки); у скидок и новинок —
  👥 сколько играют сейчас;
- «Дела» слева от часов: Enter — добавить, кружок — готово, × — удалить; хранится в `storage.sync`
  (при включённой синхронизации Firefox переезжает на другие компьютеры);
- под датой «🎮 N лет назад вышла …» — известные игры, вышедшие в этот день (Wikidata), клик — следующая;
- часы шрифтом Bebas Neue (лежит в `fonts/`, OFL).
- фон: фото дня Bing за ~2 недели вперемешку с ESA/Webb и ESA/Hubble, смена раз в 30 мин,
  ⟳ в правом нижнем углу — другой фон.

Все настройки в `config.js`: город, валюты, разделы DTF, SteamID и регион, папка закладок, интервалы.

## Как устроено

Без сборки, чистые HTML/CSS/JS, Manifest V3.

- `sources.js` — загрузчики данных (публичные API без ключей).
- `background.js` — по таймеру (`alarms`, раз в 5 мин) обновляет устаревшие источники и кладёт их в
  `storage.local`. Вкладка рисуется сразу из кэша, поэтому открывается мгновенно, а свежие данные
  подхватывает на лету (`storage.onChanged`).
- `newtab.html` / `newtab.js` / `newtab.css` — сама страница.

## Установка и обновления

Расширение подписывается на addons.mozilla.org как unlisted (не публикуется в каталоге) и обновляется
само: `manifest.json` → `update_url` указывает на `updates.json` в этом репозитории, а `.xpi` лежат в
GitHub Releases.

- **Первая установка:** скачать последний `.xpi` из Releases и перетащить в окно Firefox.
  Дальше Firefox проверяет обновления сам (раз в сутки или `about:addons` → ⚙ → «Проверить наличие обновлений»).
- **Выпустить версию:** `npm run release` — поднимает patch-версию, подписывает на AMO, коммитит,
  пушит, создаёт релиз с `.xpi` и обновляет `updates.json`. Нужны ключи AMO в переменных окружения
  `WEB_EXT_API_KEY` / `WEB_EXT_API_SECRET` и `gh auth login` (см. `scripts/release.ps1`).
- **Разработка:** `npm run dev` — отдельный Firefox с расширением, перезагружается при сохранении.

Если Steam и курсы не грузятся — `about:addons` → «Дом» → «Разрешения»: включить доступ к сайтам
(на вкладке в этом случае есть кнопка «Разрешить»).

Приложение на https://developer.spotify.com/dashboard, Web API, Redirect URI —
`https://00bb493b055e35945635d2715deb45329866269e.extensions.allizom.org/`
(то, что возвращает `browser.identity.getRedirectURL()`), Client ID — в `config.js`.
